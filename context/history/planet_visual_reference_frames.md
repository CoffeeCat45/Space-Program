## Что работает (одна модель)

| Слой | Рамка | Правило |
|------|--------|---------|
| **Core** | Инерциальная | `spinAngleRadians = ω × t`. Корабль летает. Детерминизм / lockstep MP. |
| **Unity flight** | Surface ENU, корабль в `(0,0,0)` | Планета: body-fixed точка под кораблём → Mesh Frame → восток=+X, зенит=+Y. Спин сокращается. На pad кватернион **постоянный**. |
| **Unity map** | Инерциальная | `GetMapPlanetMeshFrameSpinRotation` (F Spin F). Солнце/небо из Core. |

Handoff surface↔inertial **внутри flight** не нужен: камера flight всегда зенит=+Y (как стоять на поверхности). Инерциальный вид — это Map (M).

Мультиплеер: Core общий. У каждого клиента свой floating origin и своя surface-ENU планеты под **локальным** кораблём. Два игрока не делят один Unity transform планеты.

## Почему ломались костыли

| Попытка | Почему нельзя |
|---------|----------------|
| `FromToRotation(radial, +Y)` | Одна ось; свободный твист вокруг вертикали → тряска pad |
| Pad-lock Landed + другая формула Flying | Два кватерниона с разным yaw → земля «в бок» на отрыве |
| Shader spin, transform frozen | GEBCO чанки **не** крутят UV; география только от transform |
| Handoff 20/38/52/85 km shader↔transform | Конечные состояния отличаются на накопленный угол спина → телепорт долготы |

Формула `shipFrame × planetSpin × FromTo(mesh, body)` **геометрически верна** для точки под кораблём, но FromTo делает её **численно нестабильной**. Уникальная ENU — тот же смысл без свободного твиста; спин сокращается и не нужен на transform.

## Проверка в Play

1. Pad — без тряски, Канаверал под ракетой, A/D и тяга по носу.
2. Liftoff — земля не «влетает вбок»; ракета визуально вертикальна.
3. 20 / 38 / 85 km — без телепорта долготы (нет visual handoff).
4. Map (M) — та же суша; глобус крутится инерциально.
5. Солнце/небо — из Core (в flight движутся относительно земли).

## MP (позже, не в этом шаге)

- Core: один `spinAngle` на всех.
- Клиент: свой floating origin + своя surface-ENU планеты под локальным кораблём.
- Не пытаться крутить один Unity mesh одновременно под двух игроков в одной сцене.
