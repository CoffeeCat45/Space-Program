# Как работать с пользователем

Процесс общения и ментальная модель для AI при продолжении проекта.

Связанные заметки: [[AI_CONTEXT.md]], [[ARCHITECTURE_RULES.md]].

---

## Стиль работы

Пользователь учится постепенно, Unity знает слабо, поэтому:

- объяснять по-русски
- объяснять простым языком
- желательно пояснять по файлам: что меняется, где и зачем
- если пользователь пишет `делай`, надо сразу вносить изменения, а не только обсуждать

Пользователь ценит:

- чистую архитектуру
- предсказуемую физику
- аккуратные большие шаги
- минимальное дублирование кода

**Проверка:** только Unity Play mode. `SimulationConsole` не использовать.

## Рабочая установка для продолжения

- это не «сделай красивый космос», а «сделай предсказуемый орбитальный инструмент»
- любые изменения сначала сверять с **фактическими файлами проекта**, не только с заметками
- при сомнении приоритет у архитектуры и физической понятности, а не у эффекта
- крупные шаги предпочтительнее микроправок
- `SimulationCore` трогать осторожно и только когда действительно нужно
- актуальные задачи — [[roadmap/PROGRESS.md]] (журнал может отставать; при расхождении верить коду)

**Земля / terrain / LOD:**

- канон координат и UV: [[systems/work_terrain.md]] (Mesh Frame, Stage 4)
- суточное кручение / терминатор: [[systems/PLANET_SPIN.md]]
- cube-sphere / Nowell: [[CONVENTIONS.md]]
- runtime LOD: [[systems/LOD.md]] · тупики / F8: [[systems/LOD_FAILURES.md]]
- океан: [[systems/OCEAN.md]]
- атмосфера / облака: [[systems/ATMOSPHERE_CLOUDS.md]]
- NASA/GEBCO загрузка: [[systems/EARTH_TERRAIN_NOTES.md]] — Clean Canon: `texU = geographicU`, без runtime flip/mirror

## Кластеры и чаты (для AI)

**Один чат = один кластер** для крупных тем (4–8 подзадач, одна область). Внутри чата:

```
Следующая подзадача кластера N из PROGRESS.md. делай
```

**Новый чат** — смена кластера, >15–20 сообщений, или «чистый старт».

| Ситуация | Что писать |
|----------|------------|
| Новый чат, play loop | `@roadmap/PROGRESS.md` + кластер из журнала |
| Новый чат, новая тема | `@architecture/AI_CONTEXT.md` `@roadmap/PROGRESS.md` + промпт кластера |
| Продолжение кластера | `Следующая незакрытая подзадача кластера N. делай` |
| Мелкий баг | `@файл.cs` + описание |

**Якорь для нового чата:**

```
@architecture/AI_CONTEXT.md @roadmap/PROGRESS.md
Space Program. Unity only. SimulationConsole заморожен.
```
