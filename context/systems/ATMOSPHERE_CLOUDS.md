# Атмосфера и облака (визуал)

Два **тонких визуальных** слоя на планете. Физика атмосферы (drag, ρ) живёт в Core отдельно — не подгонять шейдер под `AtmosphereProfile` без явного запроса.

Канон dual-frame 🔒: [[work_terrain.md]] §3.1. Океан: [[systems/OCEAN.md]]. Статус: [[roadmap/PROGRESS.md]].

---

## Статус (2026-08-22)

**Облака v3 приняты** (Play: массы с просветами, без экваторного шва и без смазки вдоль параллелей, ~150–190 FPS). Не KSP EVE: нет объёма, нет полёта сквозь облако. Форму простых оболочек дальше не крутить без явной просьбы.

Третий режим: NASA PNG (`clouds-alpha.png`) — снимок, не шум. High-слой выключен.

Четвёртый: NASA PNG+ — один сэмпл на слой, ветер на восток. Dual-sample той же PNG = мыло/двоение — не возвращать.

Атмосфера: снаружи терминатор по точке касания/поверхности; ночной лимб без голубого обода.

---

## Кто что делает

| | **Физика (Core)** | **Визуал (Unity)** |
|--|-------------------|-------------------|
| Атмосфера | `AtmosphereProfile` + `ExponentialAtmosphereModel` | Сфера `PlanetAtmosphere`, шейдер `SpaceProgram/EarthAtmosphere` |
| Верх | `CelestialBody.Earth.AtmosphereTopAltitude` = **60 км** (sim-m, 1:10) | Оболочка **R + 70 км** |
| Scale height | **5000 m** (плотность/drag) | Визуал неба: **900 m** (`_ScaleHeight`), лимб **8000 m** |
| Облака | нет | Оболочки: `PlanetClouds` / `PlanetCloudsExperimental` / `PlanetCloudsNasa` / `PlanetCloudsNasaEnhanced` |

`AtmosphereView` — старое кольцо границы на карте (LineRenderer). Не путать с `FlightPlanetAtmosphereSphere`.

Dev-меню (под множителем тяги): **Визуал облаков** / **Визуал атмосферы** — полное выключение оболочек. **Видимость атмосферы** — ползунок `_Opacity` на `EarthAtmosphere` (0 = дымка выкл., 100% = как сейчас). Физика drag/ρ не трогается.

Масштаб мира: радиус Unity **637100 m** (1:10 Земли). Высоты оболочек — в тех же метрах.

## Атмосфера

Родитель — планета (крутится с Mesh Frame). Нет LOD, нет GEBCO.

| | |
|--|--|
| Код | `UnityAdapter/Flight/FlightPlanetAtmosphereSphere.cs` |
| Шейдер | `Assets/Shaders/EarthAtmosphere.shader` (`SpaceProgram/EarthAtmosphere`) |
| Меш | икосфера subdiv **6**, вершины в метрах, `localScale = 1` |
| Queue | **3000** |
| Слои | Flight: `LocalPhysics`; Map: `ScaledSpace` |

**Шейдер (важно):**

- Меш слегка раздут (**×1.08**), цвет по **ray-sphere** на истинный радиус — лимб круглый, без треугольников икосферы.
- Отсечение лиц: **VFACE**, не интерполированный `facing` (иначе дыры-грани при наборе высоты).
- Изнутри: небо, звёзды сначала в **зените** (airmass + `exp(-h/H)`), горизонт молочный дольше. `_SkyExtinction = 6.4`.
- Снаружи: Chapman-лимб. Терминатор по точке касания/поверхности. Map: всегда exterior (`_MapMode`), зум не ближе оболочки (R+115 км ×1.12), иначе камера внутри и лимб пропадал.

Не ломать: `isSupported` на атмосфере ещё есть — если шейдер не собрался, объект гасится.

**Дальний вид (Луна, перелёт, SoI):**

- Землю **не** тянуть к камере на 120 км: горизонт Луны ~120 км, диск выигрывает ZTest.
- Один мир: старт с Луны не снимает погоду Земли. Дальний глобус = PNG + NASA-облака + **тонкий** Chapman-лимб (~12 км, ~2% радиуса 1:10), не полётная оболочка 115 км (это ~18% радиуса → синий пузырь поверх Луны).
- Дети unit-глобуса в масштабе `0.5 / R`: `_ScaleHeight`/`_LimbHeight` тоже. Шейдер не должен `max(R+h, 1)` — иначе H взрывается и диск заливается.
- Queue: глобус **3050**, лимб **3070**, облака **3200**. Слой `LocalPhysics`.
- С Луны облака на диске пропадают, если глобус **Opaque + ZWrite**: на 4.5 Mm оболочка +8 км проигрывает ZTest. Лимб атмосферы живёт на каёмке, где диска нет. **Только дальний** глобус Земли в полёте — **ZWrite Off**. Карта и ближний LOD PNG Земли остаются Opaque+ZWrite, иначе geographic пропадает (чёрный диск). Не делать второй depth-mesh на Земле.
- Выход в SoI Солнца: Земля остаётся LOD-телом (не DistantCelestialGlobe). С ~1.5 Mm тот же distant-путь, что у Земли с Луны: ZWrite Off, облака +8 км, тонкий лимб. Иначе PNG перекрывает погоду, хотя Луна (distant globe) ещё видна.
- На карте после Moon→Earth SoI Луна — unit-глобус (радиус 0.5) с hibernate `FlightPlanetSphere`. Масштаб = диаметр, не `MapPositionScale` от baked-радиуса (иначе диск 0.0005 и «Луна пропала», в FP она на месте).
- Смена шейдера облаков (`material.shader = …`) сбрасывает queue на тег **3010** (Transparent+10) — **под** глобус 3050, диск затирает погоду. Дальний глобус не переключает PNG+ на статичный NASA; после любого шейдера снова **3200**. `FallBack Off` у `MapModeEarthSurface` — иначе Lit пишет depth.
- Рамка дальнего тела = полётная InverseSpin LOD, не инерциальный ENU по радиалу (иначе карта и FP показывают разные материки).
- После Moon→Earth SoI: пересобрать оболочку в метрах планеты (115 км). PNG-шелл сразу на `LocalPhysics` (не ScaledSpace — полётная камера его не рисует) и по текущей высоте, не ждать следующего LateUpdate. LOD-диск Земли — Opaque, ZWrite On.
- После Earth→Moon SoI: `ResumeFromHibernate` гасит MeshRenderer на корне (чтобы не было второго диска). Дальний глобус Земли снова **включает** этот renderer и вешает PNG; иначе остаются только облака+лимб. Не брать `GetFlightDistantColorMap` — при LOD=Луна он отдаёт лунную карту.
- В SoI Луны не масштабировать весь `FlightUniverseRoot` под far-clip Луны: Земля в небе ползёт/крутится. Scale только у LOD-меша Луны; Земля — свой `GetDistantSecondaryScale`.

## Облака (канон v3, 2026-08-21)

Те же правила геометрии, что у атмосферы: икосфера в метрах, scale 1, на планете.

| | |
|--|--|
| Код | `UnityAdapter/Flight/FlightPlanetCloudLayers.cs` |
| Шейдер | `Assets/Shaders/PlanetClouds.shader` (`SpaceProgram/PlanetClouds`) |
| Слои | Low **+1.8 км** coverage **0.44** density **1.02**; High **+7.5 км** coverage **0.48** density **0.68** |
| Queue | **3200** (после атмосферы) |
| Mesh | subdiv **3** (detail &lt; 0.34) / **4** иначе. Subdiv 5 не нужен — форма в фрагменте |
| Cull | Back снаружи, Front изнутри (мир. радиус × scale). Не `Cull Off` |
| Map | те же два слоя и тот же noise; `_CloudTime` = `simulationTime` и в полёте, и на карте (ветер). Сутки на карте — поворот меша, не шейдерный spin |

**Форма v3:** Perlin + Value FBM, domain-warp, погода рвёт просветы (не обнуляет в крошки). Климат — лёгкая сухость субтропиков с meander, **без ITCZ-полосы**. Сэмпл через `NoiseDir` (xyz→yzx), чтобы кубическая решётка не лежала на экваторе/меридианах. «Coriolis» — маленький 3D-offset, **не** `RotateY` по широте. Просветы: weather варпается уже посчитанным puff-warp (без лишних сэмплов), порог шире — без круглых «дырок от дырокола». Softness low **0.20** / high **0.22**.

**Ветер:** поворот всего поля вокруг Y (`_WindLon` low **0.000238**, high **0.0024** рад/с). Нижний ~15% медленнее прежнего 0.00028. Не east/north — на полюсе воронка.

**Свет / альфа:** Днём RGB несёт «плотность» при среднем альфа. Ночью тот же альфа + почти чёрный RGB выглядел как прозрачная плёнка (земля просвечивала). Ночь: альфа поднимается (`sqrt(density) * (1+_NightBrightness)`), `_NightCloudColor` ~ (0.055, 0.058, 0.068) — тёмный силуэт, не дырка. Солнце по-прежнему не режет альфу днём. Fake volume — два ValueNoise.

**UI:** GFX / VAB: **Cloud renderer** (`SimpleShells` / `Experimental` / `NasaPng` / `NasaPngEnhanced`). Для простых оболочек — **Cloud detail**, **coverage (густота)**, **frequency (частота)**, **clusters (скопления)**. У экспериментального — **Cloud detail** и шесть ползунков: coverage / flow / vortex / grain / mass scale / softness. NASA PNG и NASA PNG+ — без Cloud detail и без look-ползунков (карта и ветер фиксированы). Значения простых/экспериментальных в PlayerPrefs не сбрасываются. Default coverage **0.44**, frequency **1.0**, clusters **0**. Панель Terrain Graphics перетаскивается за заголовок.

**Экспериментальный рендер (2-й режим):** `PlanetCloudsExperimental`. Coverage расширяет массы (не порог альфы). Край: длинный хвост `pow(0.58)` + ridged-эрозия по кайме оболочки. Толщина шума → серое/белое + weather-slope. Grain = billow только `envelope*(1-envelope)`, океан чистый. Спирали×6, струи. 2D-оболочка.

**NASA PNG (3-й режим):** шейдер `PlanetCloudsNasa`. Карта `StreamingAssets/MapMode/clouds-alpha.png`. UV как у Земли: sim `u = lon/(2π)+0.5`, **без `1-U`**, Mesh Frame только на позициях. Сэмпл **попиксельно** из направления (не interpolated UV0 — иначе шов ±180°). Покрытие: live — A; daily white-RGB — A; JPG — luma. Полюса: LOD-размытие. Канон: [[work_terrain.md]]. High-слой выкл. Ветер UV = 0 (снимок приклеен к суше).

**NASA PNG+ (4-й режим):** шейдер `PlanetCloudsNasaEnhanced` — **отдельный**, не править `PlanetClouds` / `PlanetCloudsExperimental` / `PlanetCloudsNasa`. Та же `clouds-alpha.png`, тот же geographic UV, тот же попиксельный atan2.

Как должно работать:

- **Один сэмпл карты на слой.** Low и High — две оболочки на разной высоте, не два UV одной оболочки.
- Ветер только `u += time * _WindLon / (2π)` (на восток). Low **0.00025** рад/с, high **0.00065**.
- На старте слои **не совпадают**: low `_WindLat` = **2.4** рад (~137°), high = **0**. Это другой кусок той же карты, не призрак в 10–40°. Сдвиг high на **0.7** (~40°) при похожей плотности = копия-призрак.
- High — тонкий циррус: порог покрытия ~0.52, плотность **0.26**.
- Края не «оживлять» сдвигом UV. Жизнь = разная скорость + разная стартовая фаза.

Почему типичный промпт EVE/RSS ломает снимок NASA:

| Приём из промпта | Что видно в Play |
|------------------|------------------|
| Два сэмпла той же PNG (`UV` и `UV+warp` / `UV*1.05`) + `lerp`/`min`/`max` | Два циклона в одном месте → **двоение и мыло** (билиней + призрак) |
| High с фазой `_WindLat = 0.7` (~40°) при той же карте | Второй глобус облаков сразу, даже при t=0 |
| Flow-warp / FBM к UV макро-карты | Края размазаны, география плывёт |
| `sin(time)` или `frac(time)*2π` как фаза UV | Едет в одну сторону, **телепорт**, едет в другую (фаза обнуляется) |
| `uv.y = 1-v` / max(север, юг) | Южная погода на Арктике. Нужно было только пустому daily PNG |
| Скролл `0.02` UV/с | Оборот за ~50 с — карусель, не ветер |

Промпт для нового чата (не повторять dual-sample):

```
@context/systems/ATMOSPHERE_CLOUDS.md @context/roadmap/PROGRESS.md
Space Program. Unity only. NASA PNG+ уже в PlanetCloudsNasaEnhanced.

Канон: один сэмпл clouds-alpha.png на слой, geographic UV без 1-U, ветер только u += t*ω (на восток).
Low стартовая фаза ~2.4 рад, high 0. High тонкий. Не 10–40° (призрак), не 0.0035+ рад/с.

Запрещено без явной просьбы: второй сэмпл той же карты, UV*1.05, flow-warp/FBM на UV,
sin/frac-фаза UV, uv.y=1-v, правки PlanetClouds / Experimental / Nasa (статический).
Мыло/двоение = два смещённых сэмпла одной фотографии — не усиливать, а убирать.
```

**Почему `isSupported` нет:** объёмный прототип не компилировался и гасил весь объект. Лучше Unlit-fallback, чем пустое небо.

## Позже — облака от первого лица

Текущие две оболочки — орбита/карта. Сквозь них лететь нельзя: это 2D-плёнка на сфере.

Когда понадобится «нормальный» полёт в облаке:

1. **Оставить оболочки** для вида из космоса и map (дешёво, текущий вид).
2. **Объём только вокруг камеры**, когда высота корабля в поясе слоёв (~1.5–10 км): короткий raymarch / height-fog с 3D-шумом в view-капсуле, не по всей планете.
3. Целый планетный volume (Inner+Outer raymarch) уже пробовали — невидимость и FPS. Не повторять как основной путь.
4. Dual-frame 🔒: шум в Mesh Frame (как сейчас `RotateY` + spin), не в мировых XYZ корабля.

Пока 2D-оболочка в Play устраивает с орбиты — объём не начинать.

## Слои рендера

`FlightRenderLayers`: Flight-камера не рисует ScaledSpace-глобус; Map — наоборот. Облака и атмосфера переключаются вместе с планетой (`ApplyRenderLayer`).

## Что пробовали и не возвращать без нужды

| Попытка | Итог |
|---------|------|
| Raymarch volume / Inner+Outer | Невидимость. Объём — позже |
| Value-noise порог ~0.5 | Полотно с дырками |
| Worley | Редкие кружки |
| Ветер east/north | Закрутка на полюсе |
| `facing` по интерполированной позиции | Треугольники на выходе в космос |
| ITCZ Gaussian по широте | Сплошная экваторная лента |
| Coriolis `sign(y)` + `RotateY` | Шов на экваторе / смазка вдоль параллелей |
| Voronoi 3×3×3 + двойной FBM | ~50 FPS вместо 150–190 |
| `Cull Off` на оболочках | Двойной overdraw задней полусферы |
| Weather ×0 + жёсткий contrast | Клочки вместо масс |
| `_CLOUD_THIN` только на high | Расхождение паттерна low/high |
| NASA PNG+: dual-sample / `UV*1.05` / flow-warp | Двоение циклонов, **мыло** |
| NASA PNG+: `sin`/`frac` фаза UV | Туда-сюда, потом телепорт |
| NASA PNG+: high `_WindLat = 0.7` | Второй слой сразу смещён на ~40° |

## Не делать

- Dual-frame / Core yaw / §3.1.
- Полёт сквозь объём, пока 2D-оболочка не устраивает в Play.
- Подгонять визуальные 70 км / H=900 m под физические 60 км / H=5000 m «для порядка» — это разные системы.
- Жёстко гасить облака через `shader.isSupported`.
- Снова `RotateY` для формы облаков (ветер вокруг Y — ок).
- Снова Voronoi / второй полный FBM «для детализации».
- NASA PNG+: второй сэмпл той же PNG (мыло/двоение), `UV*1.05`, flow-warp на UV, `sin`/`frac` фаза UV, `uv.y = 1-v`, сдвиг слоя на **10–40°** (копия-призрак). Крупная фаза low ~2.4 рад — ок.
